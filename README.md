# Loan Eligibility Checker using Python

###  About the Project

The **Loan Eligibility Checker** is a Python-based case study project developed to demonstrate fundamental programming concepts through a fictional loan application process.

The project evaluates customer loan applications based on factors such as age, monthly income, loan amount, credit score, debt-to-income ratio, employment status, existing loan status, and loan term.

It also calculates the customer's **debt-to-income ratio**, determines their **credit score category**, estimates their **monthly loan repayment**, and generates an overall loan eligibility result.

All customer information and financial values used in this project are fictional and are intended for educational purposes only.

##  Project Objectives

This project demonstrates the ability to:

* Perform calculations using arithmetic operators.
* Use comparison operators to evaluate loan conditions.
* Combine conditions using logical operators.
* Use `if`, `elif`, and `else` statements.
* Use `for` loops to process multiple loan applications.
* Use `while` loops to repeatedly request valid information.
* Understand controlled infinite `while` loops.
* Create reusable Python functions.
* Pass parameters and arguments to functions.
* Return calculated values from functions.
* Understand local and global variable scope.
* Generate a structured eligibility report.
